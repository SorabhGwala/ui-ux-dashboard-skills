# Anti-Slop Rules: Eliminating AI Clichés in Web Interfaces

> **Principle:** AI models default to predictable, templated patterns that scream "generated by an LLM." Senior design director judgment rejects these shortcuts in favor of intentional, crafted, context-specific layout decisions.

---

## 1. The Banned Pattern Hall of Shame

### ❌ BANNED: The 3-Column Equal-Width Feature Card Grid
* **The Cliché:** Three identical cards side-by-side, each with a colored rounded square icon at the top, a 2-word title ("Fast Performance", "Secure Storage", "Easy Integration"), and 2 lines of generic copy.
* **Why it fails:** It communicates zero hierarchy. Every feature appears identically important; none look like real software.
* **Senior Replacement:**
  1. **Asymmetric Bento Grid:** One hero feature takes 2/3 of the row with a live interactive UI mock, while two smaller complementary features stack in the remaining 1/3.
  2. **Zig-Zag Storytelling:** Alternating left-right narrative rows: bold headline + specific metric on one side, real interactive component on the other.
  3. **Product Walkthrough Rails:** Horizontal scrolling cards with live interactive states or sticky vertical step progression.

### ❌ BANNED: Default Purple-to-Cyan Gradients
* **The Cliché:** `bg-gradient-to-r from-purple-600 to-indigo-600` or glowing radial purple blobs blurred 100px behind dark cards.
* **Why it fails:** Overused by thousands of template SaaS sites between 2021 and 2024. Immediately signals amateur or automated work.
* **Senior Replacement:**
  1. **Monochrome + Single Voltage Hue:** Pure neutral slate or deep ink (`#09090b` dark or `#f8fafc` light) with one deliberate brand accent (e.g., International Klein Blue `#002fa7`, Cursor Orange `#f54e00`, or Mint `#10b981`).
  2. **Warm Editorial Palette:** Warm cream canvas (`#f7f7f4`), deep ink text (`#1c1b18`), muted taupe borders, and crisp black buttons.
  3. **Subtle Hairline Borders:** `border border-black/[0.08] dark:border-white/[0.08]` with a faint 1px inner highlight (`inset 0 1px 0 0 rgba(255,255,255,0.05)`).

### ❌ BANNED: Meaningless Floating SVG Sparkles & Shapes
* **The Cliché:** Decorative 4-point stars, floating 3D glass donuts, or generic drawn icons floating in empty margins.
* **Why it fails:** Pure visual noise that distracts from the product value.
* **Senior Replacement:**
  1. **Functional Micro-Diagrams:** If explaining a pipeline, draw an actual 3-stage flow (Input → Processing Node → Output) with live pulsating indicator dots.
  2. **Real Brand Logos & Tools:** Show genuine tool logos (PostgreSQL, Redis, TypeScript) rather than drawn abstract shapes.
  3. **Real Photography:** High-resolution photography of real environments, actual hardware, or authentic people.

### ❌ BANNED: Generic AI Marketing Word Salad
* **The Cliché:** *"Empowering next-generation workflows through seamless intelligent synergy."*
* **Why it fails:** Says nothing, explains nothing, creates zero trust.
* **Senior Replacement:**
  1. **Plain Spoken Claims:** *"We run Postgres queries 4x faster by keeping indexes in shared memory."*
  2. **Concrete Word Budget:** 60 to 80 words per screen outside of product mocks. Keep paragraphs under 3 lines.

## 2. Structural & Layout Discipline

### 1. One Section Per Viewport (1440x900)
* At standard desktop resolution (1440x900), each section should claim its own screen space.
* Never allow the heading of section 2 to peek awkwardly 40px into the bottom of the hero section. Use generous section vertical padding (`py-24` to `py-32` / 96px to 128px).

### 2. Equal Left and Right Alignment Edges
* Choose a max-width container (e.g. `max-w-7xl` or `max-w-6xl`) and enforce identical left/right margins across the entire page.
* Avoid jarring width shifts where the header is 1400px wide, the hero is 900px, and the next section is 1200px.

### 3. Show the Real Product, Not a Placeholder
* When building for software or developer tools, render **actual live HTML UI mocks**:
  - A code review tool shows a real red/green diff with line numbers and an "Approve" button.
  - A database tool shows an actual SQL table with real columns, latency badges, and row counts.
  - An analytics tool shows live KPI cards and real sparklines, never a grey rectangle labeled "Image goes here".
