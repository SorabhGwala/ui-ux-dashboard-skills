## Reporting a Vulnerability

We take the security of this project and its downstream consumers seriously. If you discover a security vulnerability or credential leak within this repository, please do **NOT** open a public GitHub issue.

### Responsible Disclosure Process

1. **Email Privately:** Send a detailed report to **sorabhgwala@gmail.com** or open a private GitHub Security Advisory on the repository.
2. **Include Details:**
   - Description of the vulnerability.
   - Steps to reproduce or proof-of-concept.
   - Potential impact on end users or agents.
3. **Response Timeline:** You will receive an acknowledgment within **48 hours**.
4. **Resolution:** A patched release will be published before any public disclosure is made.

Thank you for helping keep our community and software safe!
